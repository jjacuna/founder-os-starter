# Log session

Save this session to the repo so the next session, and the next person,
can pick up where this one stopped.

## Steps

1. Look back over this conversation. Work out what was done, what was
   decided, what was learned, and what is left to do.
2. Pick a short topic in lowercase words joined by hyphens, for example
   `website-update`.
3. Create a new file named `history/sessions/YYYY-MM-DD-topic.md`, using
   today's date. If that file already exists, add to it instead.
4. Write the note with these headings. Use
   `history/sessions/2026-11-12-first-session.md` as the model:
   - What we did
   - What we learned
   - Decisions (only if any were made, with a link to
     `history/decisions.md`)
   - Next steps
5. Keep it short: a few bullets under each heading. Name the files that
   changed.
6. If any decisions were made, add each one at the top of
   `history/decisions.md` (newest first) in the same format as the
   entries already there: date, decision, why.
7. Only log decisions the founder actually made. If you are not sure
   something was a decision, ask.
8. Show the founder the note and any new decision entries, and ask if
   anything is missing or wrong.
9. Suggest they save the work by asking: "Commit these changes with a
   clear message".
