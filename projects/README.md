# projects/

This folder holds the plans for things you are building. One subfolder per project.

## What goes here

Each project gets its own folder with a `brief.md` inside.
A brief is a short plan: the goal, who it is for, what to make, and how you know it is done.

- [website/brief.md](website/brief.md): the plan for the starter website

The plan lives here. The thing you build lives somewhere else, like [website/](../website/) or [apps/](../apps/).

## How agents use it

Before starting work, an agent reads the brief to learn the goal and the done checklist.
It reads [company/](../company/) for the facts.

## How to add to it

1. Make a new folder with a short name, like `projects/newsletter/`.
2. Add a `brief.md`. Copy the headings from [website/brief.md](website/brief.md).
3. Ask Claude to read the brief and start.
