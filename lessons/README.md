# Lessons

Five short lessons. Do them in order. Each one takes about 10 to 15 minutes.

| Lesson | What you do |
| --- | --- |
| [1. Get set up](01-get-set-up.md) | Get the repo, open it in Claude Code, try your first prompts |
| [2. Teach it your company](02-teach-it-your-company.md) | Run `/onboard` and replace the example company with yours |
| [3. Build the website](03-build-the-website.md) | Update the website from your company facts, preview it, commit |
| [4. Agents and ultracode](04-agents-and-ultracode.md) | Meet the three agents, then run many agents at once |
| [5. Keep the history](05-keep-the-history.md) | Run `/log-session` and save what you did and decided |

## Every lesson has the same shape

- **Goal**: what you will be able to do at the end.
- **Steps**: what to click or type. Prompts to type are shown in boxes.
- **What you learned**: the ideas to remember.
- **Next**: a link to the next lesson.

## Before you start

The repo ships with a made up example company, Sunrise Dog Walking. It is
there so everything works right away. You replace it with your own company
in lesson 2.

New to all of this? That is fine. Start with [lesson 1](01-get-set-up.md).
