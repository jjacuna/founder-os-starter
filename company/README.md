# company/

This folder holds the facts about the company. One topic per file.

## What goes here

- [overview.md](overview.md): what the company is, its mission, and its goals
- [customers.md](customers.md): who the customers are and what problems they have
- [offerings.md](offerings.md): products or services, with prices
- [brand-voice.md](brand-voice.md): how the company sounds in writing

## How agents use it

Agents read these files before they write or build anything.
That is how the website, emails, and apps all say the same true things.
If a fact is not in this folder, an agent should ask instead of guessing.

## How to add to it

- Run `/onboard` to replace the example company with your own.
- To add a new topic, make a new file with a clear name, like `team.md` or `competitors.md`.
- Keep each file short. Use headings and bullets.
- When a fact changes, change it here first, then update anything built from it.
